# 9路盤 ONE MISS Board

9路盤の囲碁対局を記録・共有し、「この一手が悔やまれる」という局面を振り返るためのWebアプリです。

SGF形式の棋譜読み込み、盤面からの手入力、Firestoreへの投稿、コメント、リアクション、共有リンクに対応しています。初心者・級位者が気軽に質問や検討を投稿できる簡易掲示板を目指しています。

## 概要

- 9路盤専用の囲碁棋譜共有アプリです。
- SGFを貼り付けて対局手順を再現できます。
- 盤面をタップして黒白交互に着手し、棋譜を作成できます。
- 投稿された棋譜は一覧で確認でき、1手ずつ再生・巻き戻しできます。
- Firebase Cloud Firestoreを利用して投稿、コメント、リアクションを保存します。

## 主な機能

- 9路盤での着手
- 囲碁の基本的な石取り処理
- 自殺手・コウを含む着手禁止点の判定
- 一手戻す Undo
- SGF形式の棋譜読み込み
- 棋譜のFirestoreへの投稿
- 投稿された棋譜の一覧表示
- 棋譜を1手ずつ再生、最初・最後へジャンプ
- カテゴリ投稿（検討、質問、雑談）
- カテゴリ・未回答・コメント数による一覧フィルタ
- 投稿へのコメント
- いいね・参考になったリアクション
- 投稿ごとの共有リンク
- 日本語・英語の表示切り替え
- Firebase Firestoreによるリアルタイム同期

## 使い方

### 1. SGFから棋譜を読み込む

「投稿」画面のSGF入力欄にSGFを貼り付け、「読込」を押します。

現在のSGF読み込みは、9路盤の `B[aa]` / `W[bb]` のような基本的な着手列を対象にした簡易実装です。パス、分岐、コメント、盤サイズ違いなどのSGF拡張情報は読み込み対象外です。

### 2. 盤面から棋譜を作成する

盤面上の交点をタップすると、黒石・白石が交互に配置されます。

石取り、自殺手、コウはアプリ側で判定します。着手を取り消したい場合は「戻す」を押します。

### 3. 投稿する

カテゴリを選び、検討してほしい内容や質問を書いて「投稿する」を押します。

投稿された棋譜は「対局一覧」から確認できます。

### 4. 棋譜を再生する

対局一覧では、`|<` / `<` / `>` / `>|` ボタンを使って、棋譜を最初へ戻す、1手戻す、1手進める、最後へ進める操作ができます。

### 5. コメント・リアクションする

各投稿のコメント欄からアドバイスを追加できます。

「いいね」「参考になった」ボタンで投稿へリアクションできます。リアクション済み判定はブラウザのlocalStorageを利用しているため、厳密な不正防止ではありません。

### 6. 共有する

各投稿の「共有リンク」ボタンから、対象投稿へ直接移動できるURLをコピーできます。

## Firestoreデータ構造

現在の実装では、`posts` コレクションに投稿ドキュメントを保存します。

```text
posts/{postId}
```

投稿ドキュメントの例:

```json
{
  "text": "この局面で白はどう打つべきでしたか？",
  "category": "質問",
  "history": [
    { "idx": 40, "color": "black" },
    { "idx": 30, "color": "white" }
  ],
  "createdAt": 1791388800000,
  "comments": [
    "中央を厚く見る手がよさそうです。"
  ],
  "likes": 0,
  "helpful": 0
}
```

### フィールド

- `text`: 投稿本文。必須。
- `category`: `検討`、`質問`、`雑談` のいずれか。
- `history`: 着手履歴の配列。各要素は `idx` と `color` を持ちます。
- `history[].idx`: 0から80までの交点番号。
- `history[].color`: `black` または `white`。
- `createdAt`: 投稿時刻。現在はクライアント側の `Date.now()` を保存します。
- `comments`: コメント文字列の配列。
- `likes`: いいね数。
- `helpful`: 参考になった数。

## Firestoreセキュリティルール

公開アプリとして運用する場合は、Firestoreのルールを必ず設定してください。

このリポジトリには、現在のデータ構造に合わせた推奨例として `firestore.rules` を用意しています。Firebaseコンソールの Cloud Firestore Rules に貼り付けて利用してください。

このルール例の方針:

- 投稿の読み取りは全員に許可します。
- 投稿作成は必要なフィールドと型を満たす場合のみ許可します。
- 投稿後に変更できるフィールドは `comments`、`likes`、`helpful` のみに制限します。
- コメント数やリアクション数に上限を設けます。
- 削除は許可しません。

注意点:

- 認証なしの掲示板であるため、完全なスパム対策や同一人物判定はできません。
- `likes` と `helpful` の1人1回制限はアプリ側のlocalStorage依存です。Firestoreルールだけでは厳密に保証できません。
- 本格運用する場合は Firebase Authentication、App Check、コメントのサブコレクション化、管理者削除機能の追加を検討してください。
